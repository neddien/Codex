* Overview

Codex is a modern 2D game engine written in C++20 with an integrated editor. It features:

- *ECS* scene management via EnTT
- *OpenGL* rendering with a batched 2D sprite renderer
- *Box2D* physics (rigid bodies, colliders)
- *FMOD Studio* audio integration
- *NativeBehaviour* C++ scripting with runtime reflection
- *ImGui-based* editor with scene hierarchy, property inspector, and content browser
- Cross-platform support: Linux, Windows, macOS

** Project Structure

#+begin_src
Codex.nb/
├── codex_engine/      # Core engine (shared + static library)
│   ├── src/engine/    # Engine modules (ECS, graphics, physics, etc.)
│   ├── src/platform/  # Platform abstraction (POSIX, Linux, Windows, OpenGL)
│   └── vendor/        # Vendored header-only libs (glm, entt, stb, glad, fmod)
├── codex_editor/      # ImGui-based editor application
│   └── assets/Projects/
│       └── TemplateProject/   # Base project template for Native Behaviour scripts
├── scripts/           # Build helper scripts
├── builds/            # CMake build outputs (generated)
└── installs/          # Install outputs (generated)
#+end_src

* Prerequisites (All Platforms)

The following are required regardless of platform:

| Tool    | Minimum Version | Notes                                                      |
|---------+-----------------+----------------------------------                          |
| CMake   | 3.16            | Uses CMake Presets                                         |
| Clang   | 17+             | Primary compiler on Linux/macOS                            |
| Python  | 3.8+            | Required for the reflection tool (~python-clang~ / ~libclang~) |
| Git     | any             | Dependencies fetched via CMake                             |

Most third-party dependencies (SDL2, Box2D, ImGui, nlohmann/json, Logex) are
fetched automatically by CMake at configure time. No manual installation needed
for those. FMOD is vendored directly in ~codex_engine/vendor/fmod/~.

* Building

** Quick Start (Linux)

#+begin_src bash
# Configure
cmake --preset linux-any-debug

# Build
cmake --build builds/linux-any-debug

# (Optional) Install
cmake --install builds/linux-any-debug
#+end_src

** Ubuntu

Ubuntu's default APT repos lag behind on CMake and Clang, so extra steps are
needed to get a modern toolchain.

*** System update and helpers

#+begin_src bash
sudo apt update -y && sudo apt upgrade -y
sudo apt install -y wget software-properties-common apt-transport-https gnupg lsb-release
#+end_src

*** CMake (via Kitware APT repo)

#+begin_src bash
wget -O - https://apt.kitware.com/keys/kitware-archive-latest.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/kitware-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/kitware-archive-keyring.gpg] \
  https://apt.kitware.com/ubuntu/ $(lsb_release -cs) main" \
  | sudo tee /etc/apt/sources.list.d/kitware.list

sudo apt update -y && sudo apt install -y cmake
#+end_src

*** GCC 13 (required as a dependency for Clang's ~libstdc++~)

#+begin_src bash
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt install -y gcc-13 g++-13
#+end_src

*** Clang 17+

#+begin_src bash
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 17
sudo apt install -y clang-17
#+end_src

Optionally set Clang 17 as the default:

#+begin_src bash
sudo update-alternatives --install /usr/bin/clang   clang   /usr/bin/clang-17   100
sudo update-alternatives --install /usr/bin/clang++ clang++ /usr/bin/clang++-17 100
#+end_src

*** Python and system libraries

#+begin_src bash
sudo apt install -y \
  python3 \
  git \
  libgl1-mesa-dev \
  libx11-dev \
  libxext-dev \
  libxrandr-dev \
  libxi-dev \
  libxcursor-dev \
  libxinerama-dev \
  libxfixes-dev \
  libpipewire-0.3-dev \
  libasound2-dev
#+end_src

*** Configure and build

#+begin_src bash
cmake --preset linux-any-debug
cmake --build builds/linux-any-debug
#+end_src

** Windows

Windows supports two compiler toolchains: MSVC and Clang (LLVM). Both require
Ninja as the build tool (except the ~vs2022~ preset which generates a Visual
Studio solution).

*** Prerequisites

- [[https://visualstudio.microsoft.com/][Visual Studio 2022]] with the *Desktop development with C++* workload
  (provides MSVC, Windows SDK)
- [[https://www.python.org/downloads/][Python 3.8+]] (add to ~PATH~)
- [[https://git-scm.com/][Git]] (with SSH keys configured for GitHub)

Clang, Ninja, and libclang are best installed via [[https://scoop.sh/][Scoop]]. If you don't have
Scoop yet, install it from PowerShell:

#+begin_src powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex
#+end_src

Then install the required tools:

#+begin_src powershell
scoop install llvm ninja
#+end_src

~llvm~ includes both ~clang~/~clang++~ and ~libclang~, which is required by the
Python reflection tool (~reflector.py~ uses ~python-clang~ bindings backed by
~libclang.dll~). After installing, install the Python bindings:

#+begin_src powershell
pip install clang
#+end_src

*** MSVC (recommended)

Open a *Developer Command Prompt for VS 2022*, then:

#+begin_src bat
cmake --preset windows-msvc-any-debug
cmake --build builds/windows-msvc-any-debug
#+end_src

*** Clang/LLVM on Windows

From a *Developer Command Prompt for VS 2022* (needed for the Windows SDK and
linker), with Clang on ~PATH~ via Scoop:

#+begin_src bat
cmake --preset windows-llvm-any-debug
cmake --build builds/windows-llvm-any-debug
#+end_src

*** Visual Studio 2022 solution

To generate a ~.sln~ and work inside the IDE:

#+begin_src bat
cmake --preset vs2022
#+end_src

Then open ~builds/vs2022/Codex.sln~ in Visual Studio.
